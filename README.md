# Chapter 6 – Skeletal System Guided Notes

A static, student-editable GitHub Pages website based on the supplied 12-page guided notes. All source pictures and comparison tables are included.

## Publish
Create a **public** GitHub repository named `Chapter_6_Skeletal_System_Notes`, upload `index.html` and the entire `assets/` folder at the repository root, then open Settings > Pages > Deploy from a branch > main / (root).

Features: fill-in answers, original tissues table, 14 chapter review questions, editable annotations, section progress/navigation, highlight/unhighlight, autosave, JSON backup, PDF printing, and Google Docs-compatible HTML export. Google Docs export requires uploading the downloaded HTML into Google Drive. Student content is stored locally in their browser, not shared with the teacher.
